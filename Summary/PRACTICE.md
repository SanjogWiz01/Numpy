# Practice checklist

## Beginner
- Create 1D, 2D and 3D arrays.
- Predict the shape after every reshape.
- Extract rows/columns using slicing.
- Filter values using boolean masks.

## Intermediate
- Normalize a feature matrix.
- Replace NaN values using a column statistic.
- Build a frequency table with `unique(..., return_counts=True)`.
- Select rows using multiple conditions.
- Compare a Python loop with a vectorized NumPy expression.

## ML-focused
- Implement linear regression prediction with `X @ w + b`.
- Calculate MSE using NumPy.
- Implement standardization from scratch.
- Create one-hot encoded labels with `np.eye`.
- Compute a covariance/correlation matrix.

## Capstone
Use `25_capstone_numpy_data_cleaning.py` as a template and build your own dataset workflow:
load -> inspect -> validate -> handle missing values -> filter -> summarize -> scale -> save.
